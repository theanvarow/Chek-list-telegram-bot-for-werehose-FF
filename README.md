# Telegram Checklist Bot for Shift Handovers & Cleanliness

Этот Telegram бот предназначен для контроля чистоты и порядка на складе при смене смен. Он позволяет сотрудникам фиксировать замечания по 22 различным зонам, прикреплять фотографии и комментарии, а также формировать статистику и выгружать детальные Excel-отчеты.

## Возможности

1. **Регистрация по ФИО**: При первом запуске бот просит пользователя ввести ФИО. Введенные данные привязываются к Telegram ID и используются во всех отчетах.
2. **Проверка по 22 зонам**: Мезонины (1-5 этажи), ворота приемки, столы пересчета, зоны хранения и т.д.
3. **Интерактивный чек-лист замечаний**:
   - Пустые коробки
   - Товары на полу
   - Беспорядок
4. **Загрузка нескольких фотографий**: Бот сохраняет фотографии локально в архивную папку `photos/`.
5. **Комментарии**: Возможность оставить текстовое пояснение к проверке.
6. **Статистика**:
   - Текстовая сводка ТОП-проверяющих и активности по зонам прямо в чате.
   - Скачивание полного архива проверок в формате Excel с указанием даты, ФИО, зоны, статуса, детальных галочек по замечаниям, комментариев и локальных путей к фотографиям.

## Установка и запуск

### 1. Подготовка окружения

Убедитесь, что у вас установлен Python версии 3.8 или выше.

Установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### 2. Настройка Bot Token

1. Создайте нового бота в Telegram через [@BotFather](https://t.me/BotFather) и скопируйте полученный API Token.
2. Создайте файл `.env` в корневой директории проекта и укажите ваш токен:

```env
BOT_TOKEN=ВАШ_ТЕЛЕГРАМ_ТОКЕН_ЗДЕСЬ
```

*(Дополнительно в `.env` можно переопределить имя БД `DB_NAME` и папку для фото `PHOTOS_DIR`)*

### 3. Запуск бота

Запустите бота следующей командой:
```bash
python bot.py
```

При запуске бот автоматически:
- Инициализирует локальную базу данных SQLite (`checklist_bot.db`).
- Создаст папку `photos` для хранения загружаемых снимков.
- Начнет опрашивать сервера Telegram (long polling).

## Архитектура проекта

- `bot.py` — Главный файл запуска бота. Содержит логику состояний (FSM), клавиатуры и обработчики команд.
- `database.py` — Модуль для работы с базой данных SQLite (создание таблиц, регистрация, сохранение проверок, статистика).
- `statistics.py` — Модуль для агрегации статистики и экспорта в Excel с использованием `pandas` и `openpyxl`.
- `config.py` — Загрузка конфигурации из `.env` и список зон.
- `requirements.txt` — Список зависимостей проекта.
